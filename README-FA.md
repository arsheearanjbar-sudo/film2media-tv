# فیلم 2 مدیا — اپ تلویزیون سامسونگ (Tizen)

اپ غیررسمی تلویزیون‌های سامسونگ برای سایت فیلم 2 مدیا (`nilfgaard.top`): مرور و پخش فیلم‌ها و سریال‌های دوبله/زیرنویس‌چسبیده با کنترل تلویزیون. بدون نیاز به حساب کاربری.

## دانلود

فایل آماده `.wgt` در بخش [Releases](https://github.com/arsheearanjbar-sudo/film2media-tv/releases) گیت‌هاب قرار می‌گیرد — هر ریلیز با ورک‌فلو `Release` (تب Actions → Run workflow → انتخاب تگ مثل `v1.0.0`) به‌صورت خودکار ساخته می‌شود. نصب آن طبق راهنمای زیر با سرتیفیکیت سامسونگ انجام می‌شود.

## امکانات

| بخش | توضیح |
|---|---|
| خانه | ردیف «جدیدترین فیلم‌ها» و «جدیدترین سریال‌ها» |
| فیلم‌ها / سریال‌ها | گرید صفحه‌بندی‌شده |
| صفحه عنوان | پوستر، خلاصه داستان، لیست کیفیت‌ها (فیلم)؛ تب فصل → گرید قسمت → انتخاب کیفیت (سریال) |
| پخش‌کننده | AVPlay سامسونگ؛ چپ/راست ‎۱۰ ثانیه عقب/جلو (تکرار سریع تا ‎۶۰ ثانیه)، بالا/پایین نمایش کنترل، OK توقف/پخش، بازگشت خروج، شمارش معکوس ‎۱۰ ثانیه‌ای قسمت بعد |
| جستجو | کیبورد فارسی/انگلیسی/اعداد روی صفحه، نتایج زنده هنگام تایپ |
| علاقه‌مندی‌ها | ذخیره محلی روی تلویزیون |
| دیباگ | دکمه قرمز کنترل = لاگ روی صفحه (بدون نیاز به کنسول) |

## نصب

۱. **حالت Developer Mode تلویزیون:** وارد Apps شوید، روی کنترل `1 2 3 4 5` را بزنید، Developer Mode را ON کنید، IP کامپیوتر را وارد کنید و تلویزیون را ری‌استارت کنید.

۲. **اتصال:**
```bash
~/tizen-studio/tools/sdb connect <tv-ip>:26101
~/tizen-studio/tools/sdb -s <tv-ip>:26101 shell 0 getduid
```
خروجی `getduid` را نگه دارید — سرتیفیکیت به آن نیاز دارد.

۳. **ساخت پروفایل سرتیفیکیت** با نام `film2media`: برنامه Certificate Manager را باز کنید، Samsung و سپس TV را انتخاب کنید؛ اول author certificate بسازید (با اکانت سامسونگ وارد شوید)، بعد distributor certificate با دسترسی Public. اگر تلویزیون وصل باشد DUID آن در لیست هست؛ وگرنه دستی اضافه کنید.

۴. **ساخت و نصب:**
```bash
./build.sh
~/tizen-studio/tools/ide/bin/tizen package -t wgt -s film2media -- .
mv ./*.wgt film2media-tv.wgt    # نصب‌کننده اسم فایل فارسی را قبول نمی‌کند
~/tizen-studio/tools/ide/bin/tizen install -n film2media-tv.wgt -s <tv-ip>:26101
```

یا یک‌مرحله‌ای (ساخت + امضا + نصب + اجرا با وب‌اینسپکتور):
```bash
scripts/tv.sh <tv-ip>
```

## نکته‌های مهم

- **منبع جایگزین:** اگر فیلم 2 مدیا در دسترس نباشد (تایم‌اوت ‎۸ ثانیه)، اپ به‌صورت خودکار به منبع جایگزین (CCloud) سوییچ می‌کند و پیام «اتصال به فیلم 2 مدیا برقرار نشد — نمایش منبع جایگزین» را نشان می‌دهد. کیفیت‌ها در این حالت با برچسب «منبع جایگزین» مشخص‌اند.
- **اسم فایل فارسی:** خروجی `tizen package` از روی `<name>` ویجت (فیلم 2 مدیا) نام‌گذاری می‌شود و `tizen install` آن را رد می‌کند — حتماً قبل از نصب به اسم انگلیسی تغییرنام دهید.
- **DUID:** بدون DUID تلویزیون داخل distributor certificate، نصب با خطای سرتیفیکیت شکست می‌خورد.
- **دیباگ:** اگر چیزی کار نکرد، دکمه قرمز را بزنید؛ لاگ نشان می‌دهد API و لینک‌ها سالم هستند یا نه.
- **زیرنویس:** لازم نیست — نسخه‌های سایت زیرنویس‌چسبیده هستند.

## ساختار پروژه

- `config.xml` — مانیفست تایزن (دسترسی‌ها: اینترنت، avplay، tv.inputdevice)
- `index.html` / `css/style.css` / `js/` — اپ تک‌صفحه‌ای (بدون فریم‌ورک)
- `js/api.js` — کلاینت WordPress REST (منبع اصلی)
- `js/backup.js` — منبع جایگزین CCloud + منطق سوییچ خودکار (Source)
- `js/scrape.js` — استخراج لینک مستقیم از HTML صفحه عنوان (تست‌شده)
- `js/nav.js` — آداپتور ناوبری فضایی (spatial navigation)
- `js/player.js` — پخش‌کننده AVPlay
- `vendor-src/` — کد وندورشده spatial-navigation-core (MIT)
- `test/test-scrape.js` — تست پارسر با فیکسچر واقعی

ساخته‌شده برای استفاده شخصی؛ غیررسمی و بدون وابستگی به فیلم 2 مدیا یا سامسونگ.
